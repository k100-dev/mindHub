# Adotar dois gates de entrega para o mesmo produto

O MindHub evoluirá em um único código-base, mas será avaliado por dois gates independentes: uma demonstração acadêmica coerente e reproduzível com dados fictícios, e a prontidão de produção com persistência integrada, autorização, segurança, LGPD, integrações reais e operação recuperável. O trabalho pode avançar em paralelo, mas o cumprimento do gate acadêmico nunca autoriza descrever o sistema como pronto para pacientes reais.
